# S01A UI Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put every signed-in screen of FinFlow into a Finmap-style shell (header with «Дохід / Витрата / Переказ», module tabs «Платежі / Аналітика», a collapsible accounts sidebar with the company-currency total, a company switcher, a separate settings layout) with FinFlow's own light «fresh green» design tokens, without changing form, journal or data logic.

**Architecture:** `app/(app)/[orgSlug]/layout.tsx` (server) mounts `ShellProvider` (`lib/hooks/useShell.tsx`: URL org, accounts, categories, selected account, form launchers, sidebar/drawer state; it renders `TransactionForm` and `AccountForm` once for the whole app) and `AppShell` (`components/shell/*`). Pure logic lives in `lib/utils/accounts.ts` and `lib/shell/*` and is unit-tested. The app is light-only: `.app-shell` and `:root:has(.app-shell)` pin the shadcn CSS variables to the FinFlow palette and the `dark:` variant is switched off while a shell is on the page (dialogs and menus portal to `<body>`, so the root needs the override too). Settings become `settings/{company,categories,banks,subscription}` under a `settings/layout.tsx` menu; the Enable Banking callback returns to `settings/banks`.

**Tech Stack:** Next.js 16 App Router, React 19.2 (`useSyncExternalStore`), Tailwind CSS 4 (`@theme` tokens, `@custom-variant`), shadcn `base-nova` on `@base-ui/react` 1.x (Dialog, Menu), tailwind-merge 3 (`extendTailwindMerge`), lucide-react, Vitest 5, Playwright on the Auth + Firestore emulators. No new dependencies.

**Spec:** [2026-10-23-s01a-ui-shell-design.md](../specs/2026-10-23-s01a-ui-shell-design.md)

## Spec refinements decided while planning

Task 12 writes these into the spec.

1. **Portals and the dark root.** Dialogs, menus and selects render under `<body>`, outside `.app-shell`. The light palette is therefore set on `.app-shell` **and** `:root:has(.app-shell)`, and `@custom-variant dark` becomes `&:is(.dark:not(:has(.app-shell)) *)`: while a shell is on the page no `dark:` utility applies anywhere (landing and auth pages are unaffected).
2. **Old settings URL.** `settings/page.tsx` redirects to `settings/company` keeping the query, **except** when the query carries a bank return value (`eb_auth` or `eb_error`): then it goes to `settings/banks` (where `EnableBankingConnect` consumes it), so a bank return that was in flight during the deploy is not lost.
3. **`summarizeAccounts().count`** is the number of accounts included in the total (accounts in the company currency).
4. **URL org wins.** `ShellProvider` exposes `org` only when the loaded org is the URL's org, and calls `switchOrg(urlOrgId)` once per org id when `useOrg` restored a different one (localStorage). Header name and sidebar currency therefore always match the URL. (Partly closes the PROGRESS follow-up about `/login?redirect=/<orgB>/…`.)
5. **One categories subscription.** `useCategories` seeds default categories when the collection is empty; two concurrent subscribers on a fresh org would seed twice. `ShellProvider` subscribes once; the transactions page, `settings/categories` and `analytics/pl` read categories from `useShell()`.
6. **Forms mount on open.** `ShellProvider` mounts `TransactionForm`/`AccountForm` when opened and unmounts them on close (no change inside the forms). Each opening starts from fresh state; `TransactionForm` now preselects the first loaded account (before, it was mounted before accounts loaded and started empty).
7. **Company settings refresh the shell.** After saving name/currency the page calls `switchOrg(orgId)`, so the header and the sidebar total show the new values without a reload.
8. **Accessible names that change** (tests updated in the same task, Task 6): sidebar button «Sign out» → profile menu (`button` «Профіль») item «Вийти»; heading «Транзакції» → «Платежі»; «+ Додати рахунок» → «Додати рахунок» (sidebar); link «Analytics» → module tab «Аналітика»; the org name moves from the `<aside>` to the header (`data-testid="org-switcher-name"`). The banner test id `verify-email-banner` and the button names «Дохід», «Витрата», «Переказ» stay.
9. **`components/ui` edits.** CLAUDE.md says these files are CLI-only, but the spec asks for variants: `button` gets `soft` and a `--primary-hover` hover, `badge` gets `chip`, `table.tsx` is added by hand with the shadcn API. Each edit is marked `FinFlow (S01A)`; CLAUDE.md is updated (Task 12). Dialog, card, input, select and tabs (the `line` variant already exists) get their look from the tokens only.
10. **Journal deletion.** Today the journal has no delete action (`TransactionList` imports `deleteTransaction` but never uses it). The table keeps editing on row click (and on Enter) and adds no delete; unused imports are removed.
11. The Cash Flow empty-state link pointed to `/transactions` (404); it becomes `/<org>/transactions`.
12. `cn()` is extended (`extendTailwindMerge`) with the token radii and shadows, otherwise `cn('rounded-lg', 'rounded-control')` keeps both classes and CSS order decides.

```ts
import type { Account } from '@/types'

export interface AccountsSummary {
  /** The company currency the total is expressed in. */
  currency: string
  /** Sum of the balances of the accounts in `currency`, rounded to cents. */
  total: number
  /** How many accounts the total includes (accounts in other currencies are left out). */
  count: number
}

/**
 * Sidebar total («Разом у {currency}»): only accounts whose currency equals the company currency.
 * There are no exchange rates before S04, so other currencies are neither converted nor mentioned.
 */
export function summarizeAccounts(
  accounts: ReadonlyArray<Pick<Account, 'balance' | 'currency'>>,
  companyCurrency: string,
): AccountsSummary {
  let total = 0
  let count = 0
  for (const account of accounts) {
    if (account.currency !== companyCurrency) continue
    total += account.balance
    count += 1
  }
  const rounded = Math.round(total * 100) / 100
  // Normalise -0 (e.g. a tiny negative remainder) so the UI never renders "-0,00".
  return { currency: companyCurrency, total: rounded === 0 ? 0 : rounded, count }
}
```

```ts
import { extendTailwindMerge } from "tailwind-merge"

// FinFlow tokens from app/globals.css (S01A). tailwind-merge only knows Tailwind's default
// scales, so it must be told that `rounded-control` replaces `rounded-lg` and `shadow-pop`
// replaces `shadow-md`; otherwise both classes survive and CSS order decides.
const twMerge = extendTailwindMerge({
  extend: {
    theme: {
      radius: ["control", "field", "panel"],
      shadow: ["panel", "pop"],
    },
  },
})

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

```ts
// Settings sections (S01A). Pure: used by the settings layout, the index redirect and tests.

export type SettingsSection = 'company' | 'categories' | 'banks' | 'subscription'

export const SETTINGS_SECTIONS: ReadonlyArray<{ slug: SettingsSection; label: string }> = [
  { slug: 'company', label: 'Компанія' },
  { slug: 'categories', label: 'Категорії' },
  { slug: 'banks', label: 'Банки' },
  { slug: 'subscription', label: 'Підписка' },
]

export function settingsPath(orgId: string, section: SettingsSection): string {
  return `/${encodeURIComponent(orgId)}/settings/${section}`
}

/** The section a pathname belongs to (`/<org>/settings/<section>/...`), or null. */
export function activeSettingsSection(pathname: string, orgId: string): SettingsSection | null {
  const prefix = `/${orgId}/settings/`
  if (!pathname.startsWith(prefix)) return null
  const slug = pathname.slice(prefix.length).split('/')[0]
  return SETTINGS_SECTIONS.find((s) => s.slug === slug)?.slug ?? null
}

type Query = Record<string, string | string[] | undefined>

/**
 * Where the old single settings page (`/<org>/settings`) sends a visitor. A bank return value
 * (`eb_auth`, `eb_error`) belongs to the Banks section, which consumes it; everything else goes
 * to Company. The query string is kept as is.
 */
export function settingsIndexRedirect(orgId: string, query: Query): string {
  const params = new URLSearchParams()
  for (const [key, value] of Object.entries(query)) {
    if (value === undefined) continue
    for (const item of Array.isArray(value) ? value : [value]) params.append(key, item)
  }
  const section: SettingsSection = params.has('eb_auth') || params.has('eb_error') ? 'banks' : 'company'
  const qs = params.toString()
  return qs ? `${settingsPath(orgId, section)}?${qs}` : settingsPath(orgId, section)
}
```

```ts
// Persisted "sidebar collapsed" flag (S01A). Every storage access is guarded: private mode,
// blocked site data or a throwing accessor must never break the shell; the flag then lives in
// memory for the rest of the page session. Shaped for React's useSyncExternalStore.

export const SIDEBAR_COLLAPSED_KEY = 'finflow:sidebar-collapsed'

export type FlagStorage = Pick<Storage, 'getItem' | 'setItem'>

export function readCollapsed(storage: FlagStorage | null): boolean {
  if (!storage) return false
  try {
    return storage.getItem(SIDEBAR_COLLAPSED_KEY) === '1'
  } catch {
    return false
  }
}

export function writeCollapsed(storage: FlagStorage | null, collapsed: boolean): boolean {
  if (!storage) return false
  try {
    storage.setItem(SIDEBAR_COLLAPSED_KEY, collapsed ? '1' : '0')
    return true
  } catch {
    return false
  }
}

export interface CollapsedStore {
  subscribe: (listener: () => void) => () => void
  getSnapshot: () => boolean
  /** Server render and hydration: always expanded; the client snapshot follows right after. */
  getServerSnapshot: () => boolean
  set: (collapsed: boolean) => void
}

export function createCollapsedStore(getStorage: () => FlagStorage | null): CollapsedStore {
  // The last value set on this page wins over storage, so a failed write still toggles the UI.
  let memory: boolean | null = null
  const listeners = new Set<() => void>()
  return {
    subscribe(listener) {
      listeners.add(listener)
      return () => {
        listeners.delete(listener)
      }
    },
    getSnapshot: () => memory ?? readCollapsed(getStorage()),
    getServerSnapshot: () => false,
    set(collapsed) {
      memory = collapsed
      writeCollapsed(getStorage(), collapsed)
      for (const listener of listeners) listener()
    },
  }
}

/** `window.localStorage`, or null outside the browser or when reading the property throws. */
export function browserLocalStorage(): FlagStorage | null {
  try {
    return typeof window === 'undefined' ? null : window.localStorage
  } catch {
    return null
  }
}
```

```tsx
import {
  createContext,
  useContext,
  useEffect,
  useRef,
  useState,
  useSyncExternalStore,
  type ReactNode,
} from 'react'
import { AccountForm } from '@/components/forms/AccountForm'
import { TransactionForm } from '@/components/forms/TransactionForm'
import { useAccounts } from '@/lib/hooks/useAccounts'
import { useCategories } from '@/lib/hooks/useCategories'
import { useOrg } from '@/lib/hooks/useOrg'
import { browserLocalStorage, createCollapsedStore } from '@/lib/shell/sidebar-store'
import type { Account, Category, Organization, Transaction } from '@/types'

export type TransactionType = Transaction['type']

export interface ShellContextValue {
  /** The org id from the URL (`/[orgSlug]/...`). */
  orgId: string
  /** The loaded organization, only once it is the URL's org (null while loading or switching). */
  org: Organization | null
  accounts: Account[]
  accountsLoading: boolean
  incomeCategories: Category[]
  expenseCategories: Category[]
  categoriesLoading: boolean
  /** The account chosen in the sidebar; the journal shows only its operations. */
  selectedAccountId: string | null
  selectAccount: (accountId: string | null) => void
  openTransactionForm: (type: TransactionType) => void
  /** Without an argument: a new account. With one: edit it. */
  openAccountForm: (account?: Account) => void
  sidebarCollapsed: boolean
  toggleSidebar: () => void
  /** The phone accounts drawer (below 1024 px). */
  drawerOpen: boolean
  setDrawerOpen: (open: boolean) => void
}

const ShellContext = createContext<ShellContextValue | null>(null)

// Module level: the flag is per browser tab and survives client-side navigation between orgs.
const sidebarStore = createCollapsedStore(browserLocalStorage)

export function ShellProvider({ orgId, children }: { orgId: string; children: ReactNode }) {
  const { org: loadedOrg, switchOrg } = useOrg()
  // The only accounts/categories subscription of the shell: pages read these from the context
  // (a second useCategories on a fresh org would seed the default categories twice).
  const { accounts, loading: accountsLoading } = useAccounts(orgId)
  const { incomeCategories, expenseCategories, loading: categoriesLoading } = useCategories(orgId)

  // A selection belongs to one org: it is ignored as soon as the URL points at another one.
  const [selection, setSelection] = useState<{ orgId: string; accountId: string | null }>({
    orgId,
    accountId: null,
  })
  const selectedAccountId = selection.orgId === orgId ? selection.accountId : null

  // The forms mount on open and unmount on close, so every opening starts from fresh form state.
  const [transactionFormType, setTransactionFormType] = useState<TransactionType | null>(null)
  const [accountForm, setAccountForm] = useState<{ account: Account | null } | null>(null)
  const [drawerOpen, setDrawerOpen] = useState(false)

  const sidebarCollapsed = useSyncExternalStore(
    sidebarStore.subscribe,
    sidebarStore.getSnapshot,
    sidebarStore.getServerSnapshot,
  )

  // OrgProvider restores the last org from localStorage, which can differ from the URL (a link
  // to another company, a second tab). Load the URL's org once per org id; the ref prevents a
  // loop when the user is not a member (switchOrg then keeps the old org).
  const requestedOrgId = useRef<string | null>(null)
  useEffect(() => {
    if (!loadedOrg || loadedOrg.id === orgId || requestedOrgId.current === orgId) return
    requestedOrgId.current = orgId
    void switchOrg(orgId)
  }, [loadedOrg, orgId, switchOrg])

  const value: ShellContextValue = {
    orgId,
    org: loadedOrg && loadedOrg.id === orgId ? loadedOrg : null,
    accounts,
    accountsLoading,
    incomeCategories,
    expenseCategories,
    categoriesLoading,
    selectedAccountId,
    selectAccount: (accountId) => setSelection({ orgId, accountId }),
    openTransactionForm: (type) => setTransactionFormType(type),
    openAccountForm: (account) => setAccountForm({ account: account ?? null }),
    sidebarCollapsed,
    toggleSidebar: () => sidebarStore.set(!sidebarCollapsed),
    drawerOpen,
    setDrawerOpen,
  }

  return (
    <ShellContext.Provider value={value}>
      {children}
      {transactionFormType && (
        <TransactionForm
          key={transactionFormType}
          orgId={orgId}
          accounts={accounts}
          incomeCategories={incomeCategories}
          expenseCategories={expenseCategories}
          defaultType={transactionFormType}
          open
          onClose={() => setTransactionFormType(null)}
        />
      )}
      {accountForm && (
        <AccountForm
          key={accountForm.account?.id ?? 'new'}
          orgId={orgId}
          account={accountForm.account ?? undefined}
          open
          onClose={() => setAccountForm(null)}
        />
      )}
    </ShellContext.Provider>
  )
}

export function useShell(): ShellContextValue {
  const ctx = useContext(ShellContext)
  if (!ctx) throw new Error('useShell must be used within ShellProvider')
  return ctx
}
```

```ts
// Module tabs of the shell (S01A): only modules that exist. New tabs arrive with their modules.

export type ModuleKey = 'transactions' | 'analytics'

export interface ModuleTab {
  key: ModuleKey
  label: string
  /** First path segment after the org id that belongs to this module. */
  segment: string
  href: (orgId: string) => string
}

export const MODULE_TABS: readonly ModuleTab[] = [
  { key: 'transactions', label: 'Платежі', segment: 'transactions', href: (orgId) => `/${orgId}/transactions` },
  { key: 'analytics', label: 'Аналітика', segment: 'analytics', href: (orgId) => `/${orgId}/analytics/cashflow` },
]

/** The module a pathname belongs to: the whole first segment after `/<orgId>/`, or null. */
export function activeModule(pathname: string, orgId: string): ModuleKey | null {
  const prefix = `/${orgId}/`
  if (!pathname.startsWith(prefix)) return null
  const segment = pathname.slice(prefix.length).split('/')[0]
  return MODULE_TABS.find((tab) => tab.segment === segment)?.key ?? null
}
```

```tsx
'use client'

import { useState } from 'react'
import { useRouter } from 'next/navigation'
import { Check, ChevronDown } from 'lucide-react'
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu'
import { getUserOrganizations } from '@/lib/firebase/firestore'
import { useAuth } from '@/lib/hooks/useAuth'
import { useOrg } from '@/lib/hooks/useOrg'
import { useShell } from '@/lib/hooks/useShell'
import type { Organization } from '@/types'

type OrgList =
  | { status: 'idle' | 'loading' | 'error' }
  | { status: 'ready'; orgs: Organization[] }

// Company switcher. The list is fetched each time the menu opens (from the event handler, not an
// effect). Creating a company is S16.
export function OrgSwitcher() {
  const router = useRouter()
  const { user } = useAuth()
  const { switchOrg } = useOrg()
  const { orgId, org } = useShell()
  const [list, setList] = useState<OrgList>({ status: 'idle' })

  const load = async () => {
    if (!user) return
    setList({ status: 'loading' })
    try {
      setList({ status: 'ready', orgs: await getUserOrganizations(user.uid) })
    } catch {
      setList({ status: 'error' })
    }
  }

  const choose = (id: string) => {
    if (id === orgId) return
    // Navigate first: ShellProvider loads the URL's org as well, so the two never fight.
    router.push(`/${id}/transactions`)
    void switchOrg(id)
  }

  return (
    <DropdownMenu
      onOpenChange={(open) => {
        if (open) void load()
      }}
    >
      <DropdownMenuTrigger
        data-testid="org-switcher"
        className="flex min-w-0 max-w-64 items-center gap-2.5 rounded-control px-2 py-1.5 text-left transition-colors hover:bg-surface focus-visible:outline-2 focus-visible:outline-brand"
      >
        <span className="flex size-8 shrink-0 items-center justify-center rounded-control bg-brand font-display text-sm font-semibold text-white">
          {org ? org.name.charAt(0).toUpperCase() : 'F'}
        </span>
        <span className="min-w-0">
          <span className="block text-xs text-ink-muted">Компанія</span>
          {org ? (
            <span data-testid="org-switcher-name" className="block truncate text-sm font-semibold text-ink">
              {org.name}
            </span>
          ) : (
            <span className="mt-1 block h-3.5 w-24 animate-pulse rounded bg-line" />
          )}
        </span>
        <ChevronDown className="size-4 shrink-0 text-ink-muted" />
      </DropdownMenuTrigger>
      <DropdownMenuContent align="start" className="w-64">
        <DropdownMenuGroup>
          <DropdownMenuLabel>Ваші компанії</DropdownMenuLabel>
          {(list.status === 'idle' || list.status === 'loading') && (
            <DropdownMenuItem disabled>Завантаження…</DropdownMenuItem>
          )}
          {list.status === 'error' && <DropdownMenuItem disabled>Не вдалося завантажити компанії</DropdownMenuItem>}
          {list.status === 'ready' &&
            list.orgs.map((o) => (

                <span className="min-w-0 flex-1 truncate">{o.name}</span>
                <span className="text-xs text-ink-muted">{o.currency}</span>
```

```ts
export const UI_PASSWORD = 'ui-pass-123456'

// Filling a controlled input before React hydrates loses the value, so wait for hydration.
export async function waitForHydration(page: Page, selector: string): Promise<void> {
  await page.waitForFunction((sel) => {
    const el = document.querySelector(sel)
    return !!el && Object.keys(el).some((k) => k.startsWith('__reactProps$'))
  }, selector)
}

export interface RegisteredUser {
  email: string
  password: string
  orgId: string
  companyName: string
}

/** Registers through the real form (Auth user + organization) and lands on /{orgId}/transactions. */
export async function registerViaUi(page: Page, prefix: string): Promise<RegisteredUser> {
  const runId = `${Date.now()}${Math.floor(Math.random() * 1000)}`
  const email = `${prefix}-${runId}@finflow.test`
  const companyName = `${prefix} Co ${runId}`
  await page.goto('/register')
  await waitForHydration(page, '#name')
  await page.getByLabel('Your name', { exact: true }).fill('UI Tester')
```

```ts
import type { APIRequestContext } from '@playwright/test'

const PROJECT = 'demo-finflow'

export type Plain = string | number | boolean | null | Date | Plain[] | { [key: string]: Plain }
export type SeedFields = { [key: string]: Plain | undefined }

type FirestoreValue =
  | { nullValue: null }
  | { booleanValue: boolean }
  | { doubleValue: number }
  | { stringValue: string }
  | { timestampValue: string }
  | { arrayValue: { values?: FirestoreValue[] } }
  | { mapValue: { fields: Record<string, FirestoreValue> } }

function firestoreHost(): string {
  const host = process.env.FIRESTORE_EMULATOR_HOST
  if (!host) throw new Error('FIRESTORE_EMULATOR_HOST is not set (run inside firebase emulators:exec)')
  return host
}

function toValue(value: Plain): FirestoreValue {
  if (value === null) return { nullValue: null }
  if (typeof value === 'boolean') return { booleanValue: value }
  if (typeof value === 'number') return { doubleValue: value }
  if (typeof value === 'string') return { stringValue: value }
  if (value instanceof Date) return { timestampValue: value.toISOString() }
  if (Array.isArray(value)) return { arrayValue: value.length > 0 ? { values: value.map(toValue) } : {} }
  return { mapValue: { fields: toFields(value) } }
}

function toFields(data: SeedFields): Record<string, FirestoreValue> {
  const fields: Record<string, FirestoreValue> = {}
  for (const [key, value] of Object.entries(data)) {
    if (value !== undefined) fields[key] = toValue(value)
  }
  return fields
}

/**
 * Creates a document on the Firestore emulator as admin (`Bearer owner` bypasses the security
 * rules). Test data only; `Date` becomes a Firestore Timestamp, numbers become doubles.
 */
export async function seedDoc(
  request: APIRequestContext,
  collectionPath: string,
  docId: string,
  data: SeedFields,
): Promise<void> {
  const url = `http://${firestoreHost()}/v1/projects/${PROJECT}/databases/(default)/documents/${collectionPath}?documentId=${encodeURIComponent(docId)}`
  const res = await request.post(url, {
    headers: { Authorization: 'Bearer owner' },
    data: { fields: toFields(data) },
  })
  if (!res.ok()) throw new Error(`seed ${collectionPath}/${docId} failed: ${res.status()} ${await res.text()}`)
}
```

## Відхилення від плану під час виконання (2026-10-23)

Що змінилося під час рев'ю й виконання проти тексту задач вище (підсумкові числа на HEAD гілки: unit 467, e2e 34, rules 72, lint 0 errors / 19 warnings замість очікуваних 21):

- **Перемикач компаній: `chooseOrg` і `chosenOrgId`.** `OrgSwitcher` більше не викликає `switchOrg` + `router.push` сам, а `chooseOrg(id)` зі `ShellProvider`. Без цього синхронізація «URL перемагає» бачила щойно завантажену обрану організацію, відмінну від організації маршруту, і перемикала назад: шапка й сайдбар мигали. `chooseOrg` ставить `chosenOrgId`, ефект синхронізації не втручається, доки маршрут не дійшов до обраної компанії, а при помилці `switchOrg` прапорець скидається й показується тост. E2E перемикача двох компаній має перевірку мерехтіння.
- **`effectiveSelection`** (`lib/utils/accounts.ts`): вибраний рахунок, якого вже немає серед завантажених (видалений в іншій вкладці), вважається «усі рахунки»; вибір також прив'язано до організації (`{ orgId, accountId }`), тож він не переживає перехід в іншу компанію. - **Підсумок у сайдбарі під час завантаження:** замість хибного `0,00` показується скелет, доки не завантажено і організацію, і рахунки.
